# Alkaa Skin, Hair & Laser Clinic — Patient Acquisition Prototype

> **Client:** Dr. Apurva Vilas Shindikar (MBBS, DDV Mumbai)  
> **Location:** Indira Nagar (Main Center) & Deolali Camp, Nashik, Maharashtra  
> **Agency:** TechArtMedia (Durvesh Bhavsar)  
> **Live Demo:** Hosted on Vercel  

---

## 🎯 Overview & Strategic Objectives
This prototype was engineered by **TechArtMedia** to replace the outdated, insecure HTTP website (`alkaskinclinic.com`) and solve key patient acquisition roadblocks:
1. **100% SSL HTTPS Architecture:** Resolves alarming "Not Secure" browser warnings.
2. **Medical Dermatology Authority:** Spotlights Dr. Apurva's MBBS (Dhule), DDV (Mumbai), and Visiting Consultant credentials at Sujata Birla Hospital.
3. **1-Click WhatsApp Booking:** Pre-formats OPD appointments directly with patient details.
4. **Verified Infrastructure Showcase:** Features real Google Business Profile photos of Dr. Apurva's private consultation suite, Diode laser machines, and reception plaques.
5. **Interactive Before & After Proof:** Draggable dual-image comparison sliders for acne clearance and hair regrowth.

---

## 🛠 Tech Stack
- Pure HTML5 semantic structure
- Vanilla CSS3 with responsive design tokens & glassmorphism
- Vanilla JavaScript (touch-enabled before/after sliders, toast notifications, approval modals)
- Zero external build dependencies (instant deployment on Vercel, Netlify, or GitHub Pages)
